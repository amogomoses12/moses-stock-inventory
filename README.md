# Moses Stock Inventory App

A responsive React inventory management starter built with Vite.

## Features
- Login and separate Admin Login routes
- Protected dashboard, products, categories and settings pages
- Responsive sidebar and mobile navigation
- Dashboard KPIs, stock health, activity feed and stock movement chart
- Product create, edit, delete, search and category/low-stock filtering
- Product image URL support with image fallbacks
- Category create, edit and delete (prevents deleting categories in use)
- Settings for store name, currency and low-stock threshold
- Logout from sidebar, profile dropdown and Settings
- Data saved in browser LocalStorage

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `moses-stock-inventory` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite (usually http://localhost:5173).
